이 프로젝트의 핵심 목표는 "가상의 게임 서비스 운영 KPI 대시보드" 웹 페이지를 구현하는 것입니다. 모든 데이터는 DB 연동 없이 Mock 데이터로만 구성됩니다.

## Domain Knowledge (게임 비즈니스 지표)
이 대시보드는 게임 서비스의 핵심 성과 지표(KPI)를 다루므로, 아래의 비즈니스 용어를 이해하고 UI 데이터 구조에 반영해야 합니다.
* **DAU (Daily Active Users):** 일일 활성 사용자 수
* **MAU (Monthly Active Users):** 월간 활성 사용자 수
* **ARPU / ARPPU:** 유저당 평균 결제액 (필요 시 추가 지표로 활용)
* **매출 구성:** 월간 패스, 패키지, 유료 재화 등 게임 내 상품 카테고리별 매출 비율
